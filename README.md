# Sistemas Operacionais
Este repositório objetiva armazenar todos os arquivos desenvolvidos na disciplina SISO203 - Sistemas Operacionais, ministrada pelo Prof. Prof. Ronilson Rodrigues Pinho; M.Sc., ofertada pelo Departamento de Sistemas de Informação no Centro Federal de Educação Tecnológica Celso Suckow da Fonseca – Cefet/RJ Campus Maria da Graça, como disciplina obrigatória do Bacharelado em Sistemas de Informação.

# Proposta da disciplina
Ementa: Conceitos Fundamentais de Sistemas Operacionais. Gerência do Processador. Sistemas Monopro-gramáveis, Multiprogramáveis e Multiprocessados, Gerência de Memória. Sistemas de Arquivos; Gerenciamento de Entrada e Saída. Semáforos, Threads, Gerencia Processos e DeadLock.
